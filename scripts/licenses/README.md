License texts copied verbatim from the FFmpeg source tree at tag `n9.0.2`
(https://github.com/FFmpeg/FFmpeg/tree/n9.0.2). `scripts/fetch-ffmpeg.mjs` installs
them next to the bundled binaries, and they ship inside the installer:

- `COPYING.GPLv3` — LGPL v3 incorporates the GPL v3 by reference, and LGPL v3 §4(b)
  requires a copy of both to accompany the program.
- `FFMPEG-LICENSE.md` — FFmpeg's own explanation of its licensing.

The LGPL v3 text itself comes from the build archive (`LICENSE.txt`); it is identical
to `COPYING.LGPLv3` in this folder.
